# CMPTGCS1L2 AgendaFlow Website
This project includes:

5 HTML files

1 JavaScript file

1 CSS file

HOW TO BUILD AND RUN

This is a static website that doesn't require compiling or a build step.

To view the website:

Download or navigate to the project folder agendafolder

Open the index.html file in a web browser (double-click index.html)

Use the navigation links on the main page to access the other pages (today.html, tasks.html, officehours.html, calendar.html)

To return back to the homepage, click on AgendaFlow on the top left

CONTRIBUTIONS

All HTML, CSS, and JavaScript files for this project were organized by me.

I watched a YouTube tutorial explaining how to build an interactive real-time calendar in HTML, which helped guide the structure of the calendar component of the website. I used a Font Awesome website for the arrow images in the calendar, recommended by these tutorials.

In JavaScript, I used the built-in Date() function to retrieve and manipulate the current date.

AI tools were used for guidance during development, including explaining CSS styling properties (for example background-color, text-align, etc.), assisting with date and time calculations (like converting milliseconds into days), and helping identify and correct syntax errors in the code.

I also used online documentation and websites to learn about JavaScript LocalStorage so that user data (such as tasks) can be saved even when the browser is closed. I used this information to store tasks and calculate whether a task's due date is within three days.

Additional links, tutorials, and references used during development are documented in the Background/References section of the accompanying Google Doc. These resources were utilized throughout the development of the program.
